태그 편집

X 북마크 가져오기

PC의 크롬(또는 웨일·엣지)에서 하는 걸 권장해요. 휴대폰·아이패드에서는 잘 안 될 수 있어요.

1

버튼 만들기 처음 한 번만

  1. 아래 코드 복사를 눌러요.
  2. 브라우저 위쪽 북마크바의 빈 곳을 마우스 오른쪽 버튼으로 눌러 페이지 추가(웨일은 '북마크 추가')를 골라요. 북마크바가 안 보이면 Ctrl+Shift+B를 누르세요.
  3. 이름에 레퍼런스로 보내기, URL 칸에 Ctrl+V로 붙여넣고 저장해요.
복사가 안 될 때

아래 칸을 누르고 Ctrl+A, Ctrl+C로 직접 복사하세요.

2

X에서 모으기

  1. 새 탭에서 x.com/i/bookmarks를 열어요.
  2. 북마크바의 레퍼런스로 보내기를 누르면 오른쪽 위에 작은 창이 떠요.
  3. 가져올 개수를 적고 모으기를 눌러요. 화면이 저절로 내려가며 모아요.
  4. '준비됨'이 뜨면 복사를 눌러요.
3

여기에 넣기

  1. 이 창으로 돌아와 아래 칸을 누르고 Ctrl+V.
  2. 몇 장·몇 개가 들어가는지 확인하고 가져오기를 눌러요.
4

X 북마크 정리 원할 때만

사이트에 다 들어간 걸 확인한 뒤, X 쪽 작은 창의 모은 트윗 북마크 취소를 누르면 옮긴 트윗만 북마크에서 빠져요.

그림은 그림 탭 미분류로, 영상은 링크 탭 '영상링크'로, 글·정보는 링크 탭으로 자동으로 나뉘어요. 이미 들어 있는 트윗은 다시 넣지 않아요.
